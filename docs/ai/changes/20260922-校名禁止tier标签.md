# 校名字段禁止 tier 标签 + 后处理兜底

**日期**：2026-09-22
**涉及模块**：backend（`tools/extract_tools.py`）
**用户诉求**：文本输入简历时，学校信息有时被简化为"双一流/非双一流/普通高校"等 tier 标签，而不是完整校名。导致名单匹配失效。

---

## 1. 问题

### 提示词层

原提示词规则 5：
> bachelor_school：本科院校名称，只写校名本身（如"四川大学"），不要带专业、学历或"本科毕业于"等前缀

**没有禁止 tier 标签**。当简历原文只写"该候选人来自双一流高校"而没给具体校名时，LLM 会把"双一流"当作校名塞进 `bachelor_school` 字段。

### 后果

我们的院校层次判定逻辑 `resolve_school_tier()` 基于**真实校名**查 school_tiers.yaml 名单，"双一流"不是真实校名，名单当然查不到。LLM 的 tier 标签填了 `double_first_class`，但学校名错了，整条链路废了。

## 2. 修复：两层防线

### 第一层：提示词显式禁止（治本）

```
5. bachelor_school：本科院校**完整校名**（如"四川大学"、"中国电子科技大学"、"四川大学锦江学院"），
   禁止填"双一流"、"非双一流"、"211"、"985"、"普通高校"、"重点大学"等层次标签。
   如果原文只提层次未提具体校名，此字段填 null，层次信息写入 bachelor_school_tier。
7. 注意：**不要从 tier 标签反推校名**，两者独立抽取。
```

### 第二层：后处理兜底（治表，防 LLM 不听话）

`llm_extract()` 返回前统一过 `_sanitize_school_names()`：

```
对每个 school 字段（bachelor / graduate）：
1. 按长度降序匹配 tier 关键词（避免子串问题：非双一流 > 双一流）
2. 把所有 tier 关键词 + 常见后缀词从 school 里剥掉
3. 清孤立括号（四川大学（双一流） → 四川大学）
4. 如果剥完后没有真实校名（剩的是泛指词如 "高校" / 空字符串）：
   → tier 字段从关键词推断（双一流 → double_first_class，非双一流 → other）
   → school 字段置 None
5. 如果剥完还有真实校名（如 "四川大学（双一流）"）：
   → 保留剩余校名
   → tier 字段也从关键词推断补上
```

### 为什么两层都要

提示词再明确也挡不住 LLM 偶发的"理解偏差"——尤其是简历真的只写了 tier 标签没给校名时，模型会倾向于"把原文有的东西填进去"。后处理是确定性的，不依赖 LLM 行为。

## 3. 关键实现细节

### 关键词长度降序替换

```python
hit_keywords = [kw for kw in sorted(_TIER_KEYWORDS, key=len, reverse=True) if kw in school_str]
```

避免子串覆盖问题：`非双一流本科` 如果先替换 `双一流`（3 字），会剩 `非本科`；先替换 `非双一流`（4 字）才能正确全部剥掉。

### 短文本泛指后缀清理

```python
if len(remaining) <= 6:
    for suf in REMOVE_SUFFIXES:  # ("高校", "学校", "本科", "学院", "大学", ...)
        if remaining == suf:
            remaining = ""
```

`普通本科高校` 剥掉 `普通本科` 后剩 `高校`，只有 2 字且是泛指后缀 → 判为无真实校名。只有短文本才做这个判断，避免误伤真实校名的一部分（比如"电子科技大学"里的"大学"）。

### 括号清理

用 `re.sub(r"[（()）]", "", remaining)` 剥掉所有括号，孤立括号全清，不区分中英文。

## 6. 边界：真实校名被误判？

当前阈值是"剩余文本 ≤ 6 字且等于泛指后缀词 → 清空"。真实校名最短也是 2+2（如"交大"不行，太短；"川大"也只有 2 字 → 但简历里几乎不会只写"川大"两个字，多数会写"四川大学"）。如果真遇到边界 case，可以调低阈值或改启发式（比如检查剩余文本是否是已知名单的子串）。

但在**真实简历**里，"普通本科高校"/"双一流" 这种表达**永远不会同时出现具体校名**——如果简历写了"四川大学（双一流）"，LLM 会抽成完整校名 + tier，后处理只做剥离标签，**不会**误清校名。
